## 🧠 المواضيع اللي درسناها في السيشن
 
- The DOM (Document Object Model) — التعامل مع `document`
- `document.all` — الوصول لكل عناصر الصفحة
- التفرقة بين Node و Element (`childNodes` مقابل `children`)
- `hasChildNodes()` — التحقق من وجود عناصر داخلية
- `parentNode` / `parentElement`
- طرق الوصول للعناصر:
  - `getElementsByTagName()`
  - `getElementById()`
  - `getElementsByClassName()`
- التنقل بين العناصر (DOM Traversal):
  - `nextSibling` vs `nextElementSibling`
  - `previousSibling` vs `previousElementSibling`
  - `firstChild` vs `firstElementChild`
  - `lastChild` vs `lastElementChild`
  - `childElementCount`
- الـ Attributes:
  - `hasAttributes()`
  - `attributes`
  - `getAttribute()` / `setAttribute()`
- التعامل مع محتوى العنصر:
  - `innerHTML`
  - `innerText`
  - `textContent`
- التحكم في الـ Style عن طريق JavaScript (`element.style.property`)
- إنشاء وإضافة عناصر جديدة:
  - `document.createElement()`
  - `appendChild()`
