## 🧠 المواضيع اللي درسناها في السيشن

- HTML5 وأهم الفروق بينها وبين HTML4
- الـ Semantic Tags الجديدة وأهميتها في تنظيم الصفحة:
  - `header`
  - `nav`
  - `main`
  - `aside`
  - `section`
  - `article`
  - `footer`
- الفرق بين استخدام `div` العادي واستخدام الـ Semantic Tags
- أنواع الـ Inputs الجديدة في HTML5:
  - `datetime` / `datetime-local`
  - `number` (مع `min`, `max`, `step`)
  - `range` (مع `min`, `max`, `step`)
  - `url`
  - `tel`
  - `search`
  - `month`
  - `week`
  - `color`
- الـ `output` element وربطه بعناصر الفورم باستخدام `for`
- قراءة القيم الرقمية من الـ inputs باستخدام `valueAsNumber`
- التحقق من دعم المتصفح لخاصية معينة (Feature Detection) باستخدام Modernizr:
  - `Modernizr.inputtypes`
  - التعامل مع الحالة لو الخاصية مش مدعومة (`setAttribute`)
- الـ Media Elements الجديدة في HTML5:
  - `audio`
  - `video`
  - استخدام `source` لتحديد أكتر من صيغة للملف (`mp3`, `ogg`, ...)
  - المحتوى البديل لو المتصفح مش بيدعم العنصر
- خصائص وميثودز الـ `audio`/`video`:
  - `play()`
  - `pause()`
  - `load()`
  - `paused`
  - `muted`
  - `volume`
  - `currentTime`
  - `duration`
  - `autoplay` / `loop`
- الـ Events الخاصة بالـ Media:
  - `timeupdate`
  - `durationchange`
- ربط الـ `range` input بالتحكم في الـ progress والـ volume بتاع الصوت
