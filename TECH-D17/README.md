## 🧠 المواضيع اللي درسناها في السيشن

- الـ `canvas` element في HTML5 وإزاي بنستخدمه لرسم جرافيكس ثنائية الأبعاد
- عمل الـ Context بتاع الرسم باستخدام `getContext("2d")`
- رسم الأشكال المستطيلة:
    - `fillRect()` لرسم مستطيل ممتلئ
    - `strokeRect()` لرسم مستطيل بالحدود بس
- التحكم في شكل الرسم:
    - `fillStyle` لتحديد لون التعبئة
    - `strokeStyle` لتحديد لون الحدود
    - `lineWidth` لتحديد سمك الخط
- رسم الخطوط والمسارات (Paths):
    - `beginPath()` لبدء مسار جديد
    - `moveTo(x, y)` لتحديد نقطة البداية
    - `lineTo(x, y)` لتحديد نقطة النهاية والرسم لها
    - `stroke()` لتنفيذ رسم الخط
- رسم الأقواس والدوائر باستخدام `arc()`:
    - تحديد المركز ونصف القطر
    - زاوية البداية والنهاية (بالراديان)
    - اتجاه الرسم (`clockwise` / `counterclockwise`)
    - `fill()` لتلوين الشكل الناتج
- الفرق بين استخدام أكتر من `beginPath()` عشان تفصل بين كل شكل والتاني
- الـ `@font-face` في CSS واستخدامه لتحميل فونتات مخصصة (Custom Fonts):
    - تحديد `font-family` باسم مخصص
    - تحديد مصدر الفونت عن طريق `src` و `url()`
    - استخدام الفونت المخصص في العناصر بتاعتنا زي أي `font-family` عادي
