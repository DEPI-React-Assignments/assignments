## 🧠 المواضيع اللي درسناها في السيشنز

### ⚛️ الـ Hooks والـ Lifecycle

- شرح `useEffect` وكيفية استخدامه في الـ first render وتهيئة البيانات عند تحميل الصفحة
- فهم الفرق بين تشغيل الـ effect بدون `dependency array` وبتواجدها كـ `[]` أو مع مجموعة محددة من المتغيرات
- استخدام الـ `cleanup function` لتنظيف الموارد قبل التحديث أو قبل إلغاء الـ component
- تطبيق عملي على تحديث الـ state وقياس تأثير التحديثات على الـ UI

### 🔄 التعامل مع الـ Data والـ State المتقدم

- تحديث الـ state بشكل آمن عن طريق عمل نسخة من الـ Arrays والـ Objects قبل التعديل
- استخدام `map()` و`filter()` لتحديث القوائم والحذف والتصفية
- التعامل مع حالة الـ Loading أثناء جلب البيانات من الـ API
- عرض رسالة `No Products Found` عند عدم وجود منتجات بعد الفلترة
- تحديث عداد المنتجات في الـ navbar بناءً على العناصر الموجودة داخل السلة

### 🛒 مشروع المتجر الإلكتروني المتقدم

- جلب قائمة المنتجات والفئات من `json-server` باستخدام `fetch` أو `axios`
- حفظ البيانات في الـ state وعرضها داخل الصفحة الرئيسية
- فلترة المنتجات حسب الفئة المختارة
- إضافة نظام `Pagination` لعرض النتائج على صفحات متعددة
- إضافة المنتج إلى السلة وتحديث عدد المنتجات في الـ navbar
- زيادة/تقليل الكمية، إعادة تعيين السلة، وحذف عنصر من السلة

### 🧭 التنقل المتقدم باستخدام React Router

- إعداد `BrowserRouter` و`Routes` و`Route` لتحديد الصفحات داخل التطبيق
- استخدام `NavLink` و`Link` لتنقل المستخدم بين الصفحات ومعالجة الـ active state
- قراءة بيانات المسار باستخدام `useParams`
- قراءة الـ Query Parameters عبر `useSearchParams`
- التنقل البرمجي باستخدام `useNavigate` مع تمرير `state` أثناء الرحلة
- استخدام `useLocation` للوصول إلى معلومات الصفحة الحالية
- عرض صفحة `ErrorPage` عند إدخال مسار غير موجود

### 🧠 Context API

- إنشاء `createContext` وتهيئة الـ Provider
- تمرير البيانات عبر الـ Context إلى مكونات متفرقة داخل التطبيق
- استخدام `useContext` لاسترجاع القيم من الـ Context واستخدامها بسهولة

### ✅ Form Handling والتـ Validation

- التعامل مع الـ controlled inputs في النموذج
- استخدام `useState` لتخزين بيانات النموذج عند كل تغيير
- التحقق من صحة البريد الإلكتروني وكلمة المرور باستخدام `Yup`
- عرض رسائل الخطأ لكل حقل بشكل منفصل
- التحقق من البيانات قبل إرسال النموذج
